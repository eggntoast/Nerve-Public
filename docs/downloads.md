# Downloads

Nerve **0.1.0 is a release candidate**. There are no public addon downloads yet.

The planned main download is CurseForge for TBC Anniversary. Approved client-specific packages will also be clearly labelled on [GitHub Releases](https://github.com/eggntoast/Nerve-Public/releases). A CurseForge link will be added when the project is available.

Choose the package matching your client. Do not combine the TBC and Forever packages. GitHub's automatic source archives and Code → Download ZIP are not installable addons.

Only Warrior is currently supported. Forever Victory Rush still awaits in-game verification.
