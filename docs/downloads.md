Install the **Nerve** folder from the Forever ZIP. GitHub’s **Code → Download ZIP** contains this gallery and its help pages, not an installable addon.

## Current support

Nerve supports Warrior’s **Execute, Overpower, Revenge and Victory Rush**, with twelve styles and per-character settings.

Victory Rush stays hidden during its own cooldown. Its optional fade uses the buff’s remaining time when the game provides it; otherwise, the overlay stays steady.

The plan is to add the other classes one at a time until all nine are supported.
